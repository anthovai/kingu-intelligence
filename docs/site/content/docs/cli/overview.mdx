The Kingu CLI is the `kingu` command-line interface for scripting a running Kingu editor from any shell. Use it to create and inspect worktrees, drive agent terminals, open files and diffs, automate the built-in browser, run scheduled automations, share HTML/Markdown artifacts, and control Kingu-native tools from scripts or AI agents.

It ships with the desktop app; register it under [Settings → General → Kingu CLI](/docs/settings). On Linux the command is `kingu-ide`, because GNOME Kingu's screen reader already owns `/usr/bin/kingu` — see [Install → Linux](/docs/install#linux).

Agents can install the matching Kingu CLI skill with:

```bash
npx skills add https://github.com/anthovai/kingu-intelligence --skill kingu-cli
# headless / no Settings UI:
kingu skills install --skill kingu-cli
```

See [Skills registry & MCP](/docs/cli/skills) for every installable Kingu skill, including `kingu skills install` / `kingu skills update`.

## Install & verify

```
command -v kingu
kingu status --json
```

## Worktree commands

```
kingu worktree ps --json
kingu worktree create --repo id:<repoId> --name my-task --issue 123 --json
kingu worktree current --json
kingu worktree set --worktree active --comment "reproduced bug" --json
kingu worktree rm --worktree id:<id> --force --json
```

For selectors, setup flags, parent/child worktrees, and the broader command map, see [Kingu CLI reference](/docs/cli/reference).

## Terminal commands

```
kingu terminal list --json
kingu terminal read --json
kingu terminal send --text "continue" --enter --json
kingu terminal wait --for tui-idle --timeout-ms 30000 --json
kingu terminal create --worktree path:/projects/app --command "npm test" --json
kingu terminal split --direction vertical --command "npm run dev" --json
```

For tracked multi-agent work, use [Orchestration](/docs/cli/orchestration) instead of plain terminal prompts.

## File commands

Open files and diffs in the active Kingu worktree from a shell:

```
kingu file open src/App.tsx
kingu file diff src/App.tsx --staged
kingu file open-changed --mode both
```

Use `--worktree <selector>` when the shell's current directory is not inside the target worktree.

## Browser profiles

Browser profiles isolate tab session state, so a script or agent can test with different cookies, local storage, and logged-in identities. The CLI exposes profile commands under `kingu tab profile`; start with `kingu tab profile list --json`, then use `create`, `set`, `clone`, or `use-default` as needed.

## Scheduled automations

Use `kingu automations` to create, inspect, run, and remove scheduled Kingu tasks from a shell. Start with [Scheduled automations](/docs/cli/automations) when you want a recurring prompt to run against a repo or an existing worktree.

## Artifacts

Share HTML or Markdown as public view links through the signed-in Kingu account (`kingu artifacts share|update|list|delete`). Publishing is **opt-in** under Settings → Artifacts. Command details: [CLI reference → Artifacts](/docs/cli/reference#artifacts).

## Browser automation

The CLI also drives the built-in browser with a snapshot-interact-re-snapshot loop:

```
kingu goto --url https://example.com --json
kingu snapshot --json     # returns refs like @e1, @e3
kingu click --element @e3 --json
kingu fill --element @e1 --value "user@example.com" --json
kingu screenshot --json
```

For responsive browser checks, switch the active tab to a named device profile:

```
kingu set device --name "iPhone 12" --json
kingu screenshot --json
```

## Mobile emulator

The CLI can also drive an iOS Simulator through Kingu's mobile emulator bridge. It is scoped to the active worktree, so agents and scripts can attach a simulator from `kingu emulator list`, tap normalized coordinates, type text, send gestures, rotate the device, and shut it down without leaving Kingu.

```
kingu emulator list --json
kingu emulator attach "<device-name-or-udid>" --json
kingu emulator tap 0.5 0.7 --json
kingu emulator type "hello" --json
kingu emulator gesture '[{"type":"begin","x":0.5,"y":0.8},{"type":"move","x":0.5,"y":0.4},{"type":"end","x":0.5,"y":0.2}]' --json
kingu emulator rotate landscape_left --json
kingu emulator kill --json
```

Use `--worktree <selector>`, `--device <udid-or-name>`, or `--emulator <id>` when a script needs an explicit target.
